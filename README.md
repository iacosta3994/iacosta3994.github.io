# iacosta3994.github.io

Personal site for Blizen. Published at <https://iacosta3994.github.io/>.

Static HTML and CSS. Edit `index.html` and `style.css` on `main`.

Most played Steam games are filled from `games.json`. `.github/workflows/steam-games.yml` refreshes that file once a day when the Steam game list is public, or when the `STEAM_API_KEY` repository secret is set.
